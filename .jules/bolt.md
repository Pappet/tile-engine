## 2024-05-28 - Pre-filtering active periodic reactions
**Learning:** In the voxel simulation (`periodic_reaction_system`), evaluating the periodic trigger phase offset for every reaction inside the O(Chunks * ChunkArea) inner loop causes unnecessary redundant checks. Since chunk evaluation order and chunk count doesn't affect which reactions are active in a given tick, the active reactions should be pre-filtered and fetched ahead of time.
**Action:** When implementing multi-pass loop evaluations like cellular automata over chunk data, pre-filter loop invariants (like active events or registry entries matching the current tick) into a buffer (`Vec`) *before* iterating over chunks and tiles. This reduces redundancy from O(Chunks * TotalReactions) down to O(TotalReactions + Chunks * ActiveReactions).
