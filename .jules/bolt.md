## 2024-06-08 - Short-circuiting and Cross-crate Inlining
**Learning:** In hot simulation loops (like cellular automata multi-pass systems), evaluating cheap stateless checks (like `mix_hash` probability rolls) before expensive dynamic condition evaluations allows short-circuiting execution for low-probability events, avoiding expensive registry lookups. Additionally, small, frequently called math functions used across crate boundaries (like `mix_hash`) must be explicitly marked `#[inline]` to guarantee cross-crate inlining by LLVM and avoid function call overhead.
**Action:** When implementing condition checks in simulation hot paths, always evaluate pure stateless math probability rolls before any stateful array or registry reads. Always add `#[inline]` to small cross-crate utility functions.
